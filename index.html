درباره و حریم خصوصی
فطرس ۲.۰ — «همراه لحظه‌های زندگی». بدون حساب، بدون سرور، بدون تبلیغ، بدون ردیاب.
• تقویم: تبدیل شمسی/میلادی دقیق (الگوریتم jalaali-js تأییدشده)؛ قمری جدولی است و ممکن است ‎۱± روز با رؤیت هلال تفاوت داشته باشد.
• اوقات شرعی: محاسبهٔ نجومی محلی (بدون API پولی) با روش‌های تهران/MWL/مصری/کراچی/ام‌القری.
• آب‌وهوا (اختیاری): از Open-Meteo (رایگان و بدون کلید) — فقط وقتی آنلاین باشید.
• مکان: فقط با اجازهٔ شما و فقط برای محاسبهٔ اوقات/قبله/آب‌وهوا استفاده می‌شود و به جایی ارسال نمی‌شود.
• دسترسی‌ها: اعلان و حسگر جهت فقط با اجازهٔ صریح؛ همه را می‌توانید در تنظیمات مرورگر لغو کنید.
• متن‌باز فرضی: قبل از انتشار عمومی، مجوز فونت «رخ» را بررسی کنید.
ساخته‌شده با HTML/CSS/JS خام — بدون فریم‌ورک، بدون بیلد.

نصب و آفلاین
برای نصب: در Chrome اندروید → منوی ⋮ → «Install app» یا «Add to Home screen».
PWA فقط روی https:// یا localhost کار می‌کند، نه file://.
برای به‌روزرسانی: وقتی «نسخهٔ جدید» آمد، روی «به‌روزرسانی» بزنید تا کش تازه شود.
در نسخهٔ مرورگر: با «Install app» فطرس مثل یک برنامهٔ واقعی نصب می‌شود و بعد از بار اول، کاملاً آفلاین باز می‌شود.
راهنمای APK (خلاصه)
راهنمای کامل در README.md (§۱۰) است. خلاصه: با یک push روی شاخهٔ main (یا Actions → «Build FETROS Android APK» → Run workflow) یک APK دیباگ ساخته می‌شود که فایل‌های وب داخل خودش است → از GitHub Release v2-debug روی گوشی دانلود → «نصب از منبع ناشناخته» روشن → Install.
