FETROS — پوشهٔ صدا / Audio folder
─────────────────────────────────
این پوشه برای فایل‌های اختیاری صدا است:
- azan.mp3   → پخش اذان هنگام وقت نماز (در پیش‌زمینه)
- tick.mp3   → صدای کوتاه تیک ذکر (اختیاری)
- notif.mp3  → صدای اعلان یادآور (اختیاری)

چطور از روی گوشی فایل بگذارید:
1. فایل mp3 را دانلود کنید (فقط فایل‌هایی را استفاده کنید که اجازهٔ استفاده دارید).
2. با برنامهٔ «Files» گوشی، فایل را به پوشهٔ پروژه /audio منتقل کنید و نامش را دقیقاً azan.mp3 بگذارید.
3. در تنظیمات فطرس، «پخش اذان» را روشن کنید و «تست صدا» را بزنید.

نکته‌ها:
- مرورگرها فقط وقتی تب باز است اجازهٔ پخش خودکار می‌دهند؛ پخش پس‌زمینهٔ مطمئن نیاز به بسته‌بندی APK و سرویس بومی دارد (در README توضیح داده شده).
- اگر فایلی اینجا نباشد، برنامه بدون خطا و بدون صدا کار می‌کند.
- برای کاهش حجم، فایل‌ها را زیر 2MB نگه دارید (mp3 با بیت‌ریت 64–96kbps کافی است).

English:
Place optional audio files here:
- azan.mp3 for azan playback (foreground only in PWA)
- tick.mp3 for dhikr tick (optional)
- notif.mp3 for reminder sound (optional)
No audio file is required for the app to work.
