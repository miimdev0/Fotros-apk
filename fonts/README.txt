پوشهٔ فونت — fonts/
====================

فطرس از فونت «رُخ» (Rokh) استفاده می‌کند. این فایل را شما باید اضافه کنید
(اجازهٔ دانلود خودکار فونت در این پروژه نیست و فایل باینری جعلی نمی‌سازیم).

۱) دانلود فونت رُخ
   - به صفحهٔ رسمی فونت رُخ بروید (جستجو کنید: «فونت رُخخ ROKH font github»).
   - فایل TTF با وزن معمولی را بگیرید.
   - ⚠️ قبل از انتشار عمومی، مجوز (License) فونت را حتماً بخوانید.
     رُخ معمولاً با مجوز آزاد (SIL OFL) منتشر می‌شود؛ در صورت commercial
     بودن پروژه، مجوز را دوباره بررسی کنید.

۲) تغییر نام فایل
   نام فایل باید دقیقاً این باشد:  Rokh.ttf
   (حساس به بزرگ/کوچکی حروف: Rokh.ttf نه rokh.ttf)

۳) کجا بگذارم؟ (با گوشی اندرویدی)
   - اگر پروژه را روی GitHub دارید: در اپ GitHub → پوشهٔ fetros → وارد
     پوشهٔ fonts شوید → «Add file» → «Upload files» → فایل Rokh.ttf را انتخاب کنید.
     (پوشهٔ fonts همین حالا با همین فایل README وجود دارد.)
   - اگر روی حافظهٔ گوشی هستید: با اپ «Files» فایل را به مسیر
     fetros/fonts/ منتقل کنید.
   - اگر با Termux کار می‌کنید:
       mv ~/storage/downloads/Rokh.ttf ~/fetros/fonts/Rokh.ttf

۴) تست
   - صفحه را یک‌بار با Refresh کامل (Ctrl+Shift+R یا Clear cache از
     تنظیمات فطرس) باز کنید.
   - متن‌ها باید با رُخ نمایش داده شوند. اگر فایل نباشد، برنامه با
     فونت Vazirmatn/سیستمی ادامه می‌دهد و هیچ خطایی نمی‌دهد.

نکته‌ها
   - اگر فونت شما «متغیر» (variable) است، همان Rokh.ttf کافی است؛
     style.css بازهٔ وزنی ۱۰۰ تا ۹۰۰ را اعلام کرده است.
   - اگر فونت ثابت (static) است و وزن ۹۰۰ ندارید، نگران نباشید:
     عنوان‌ها با همان فایل رندر می‌شوند و synthetic bold برای تیترها
     استفاده نشده (جایش با اندازه و فاصلهٔ حروف تنظیم شده است).
   - سرویس‌ورکر (sw.js) نبودِ فایل را تحمل می‌کند؛ نصب کش خراب نمی‌شود.
